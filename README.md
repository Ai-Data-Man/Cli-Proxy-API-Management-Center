# Cli Proxy API Management Center — Ai-Data-Man Fork

This is a **maintained fork** of [router-for-me/Cli-Proxy-API-Management-Center](https://github.com/router-for-me/Cli-Proxy-API-Management-Center).

Upstream is a single-file Web UI (React + TypeScript) for operating and troubleshooting CLI Proxy API via its Management API (config, credentials, and logs).

## What We Changed

- **CI/CD**: Added `workflow_dispatch` and `release/edited` triggers; enhanced publish workflow with SHA256 digest
- **Usage Statistics**: **Restored** the "Usage Statistics" feature page and related components (removed upstream since v6.10.0)
- **Fixes & maintenance**: UI style improvements, OpenAI provider card fixes, build toolchain upgrades, dependency updates
